# Phase 6.4 Test Checklist

## Generation
- Advance several weeks in multiple settlements
- Confirm different major event types appear
- Confirm event likelihood reflects shortages, damage, faction instability, social tension and spirit pressure

## Lifecycle
- Watch an event form, become active, resolve and enter history
- Ignore at least one event completely
- Confirm it still resolves without player involvement

## Player participation
- Observe an event
- Help an event
- Organize a response
- Oppose a response
- Confirm involvement changes momentum but does not guarantee success

## Consequences
- Check prosperity after economic events
- Check damage/infrastructure after disasters or projects
- Check faction stability after political/crime events
- Check spirit balance after spirit events
- Check NPC migration and health where relevant

## Integration
- Confirm active events appear in World Director daily context
- Save/reload during an active event
- Confirm progress/history persists
