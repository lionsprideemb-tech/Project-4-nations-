# Phase 6.6 Test Checklist
- Make a promise to an NPC, leave, return later, and talk again
- Tell an NPC a secret and confirm unrelated NPCs do not automatically know it
- Perform an important action in front of witnesses
- Return to a witness later and confirm the memory is available to narration
- Build trust with one NPC and tension with another; compare later reactions
- Create a fight, favor, insult, romantic moment, or other major shared event
- Confirm major shared moments persist after save/reload
- Confirm low-value memories can eventually fade while high-importance memories remain
- Inspect Memories and verify source labels distinguish witnessed, direct, shared, and heard information
